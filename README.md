# Portfolio

This is my personal engineering portfolio that shows projects I worked on across biomedical engineering, AI/ML, data, electronics, and product development.

It was inspired by the "Letter Portfolio" template by "riceball-tw". It was built with Astro and Tailwind CSS, with the project and experience content managed through Astro content collections.

## Tech Stack

- Astro 7
- Tailwind CSS 4
- TypeScript
- MDX
- Astro Content Collections
- Astro Icon
- Astro SEO

## Local Development

```bash
# Install dependencies
pnpm install

# Start the development server
pnpm run dev
